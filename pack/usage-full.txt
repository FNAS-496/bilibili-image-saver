====================================================
  Bilibili-Plus v@@VERSION@@ · 完整版（内置 Node.js + FFmpeg）
====================================================

本包是「环境版」+ 内置运行环境：浏览器脚本负责页面上的操作，本地服务负责
真正把文件写进硬盘，而 Node.js 和 FFmpeg 都已经放在包里了。
整个文件夹直接发给别人就能用，什么都不用装。

想省这 70 MB 的运行时？那就下「环境版」（自己装 Node）或「便携版」
（纯浏览器，零安装），两个都在项目主页的发行包列表里。

----------------------------------------------------
一、运行环境（本包已内置，一行都不用配）
----------------------------------------------------
    node\node.exe          内置 Node.js（本地保存服务用它跑）
    ffmpeg\ffmpeg.exe      内置 FFmpeg（视频音画合并用）

「一键启动.bat」会自动把本目录的 node\ 放进 PATH，所以：
    · 自己电脑没装 Node —— 照常用；
    · 自己电脑装了 Node —— 也优先用包里的这份（版本可控）。

----------------------------------------------------
二、怎么装（只装一次）
----------------------------------------------------
1. 浏览器装 Tampermonkey 扩展（Chrome / Edge 应用商店搜 Tampermonkey）
2. 双击本目录的 bilibili-save.user.js，弹出安装页点「安装」

----------------------------------------------------
三、怎么用
----------------------------------------------------
1. 双击「一键启动.bat」：
   - 用包内 node\node.exe 启动本地保存服务（端口 8765，只监听本机）
   - 自动打开 B 站
2. 打开收藏夹 / 动态 / 作品页：
   - 页面右下角自动提取原图并保存，不用点任何按钮
3. 视频下载（可选）：
   - 视频页或收藏夹页右下角「📹 视频下载」→ 勾选 → 下载选中
   - 已经是内置 ffmpeg，会自动合并成一个带声音的 mp4（4K / HDR 也行）
4. 图片相册页：浏览器打开 http://127.0.0.1:8765/ 就能看已保存的图片
5. 停服务：关掉「Bilibili-Plus 保存服务」那个黑窗口就行

----------------------------------------------------
四、文件存哪
----------------------------------------------------
默认是桌面上的「B站下载」文件夹（兼容 OneDrive 重定向的桌面）：
    B站下载\            ← 图片
    B站下载\videos\     ← 视频
想换地方：先在设置里改「保存位置」，或在本目录的 outdir.txt 里写路径；
也可以在「一键启动.bat」顶部把 SAVE_DIR 填成你的路径。

----------------------------------------------------
五、文件都是干啥的
----------------------------------------------------
见同目录的「文件说明.txt」：每个文件是干啥的、哪个能删、哪个别手改，一条条列好了。
（node\ 和 ffmpeg\ 删了就用不了内置运行时，包整个就退化成「环境版」了。）

----------------------------------------------------
六、常见问题
----------------------------------------------------
Q：提示「未连接本地保存服务」？
A：黑窗口被关了，或者没启动。再双击一次「一键启动.bat」，然后刷新 B 站页面。

Q：提示「缺少 Node.js」？
A：包里的 node\node.exe 不在了（被杀毒软件删了？被手动清理了？）。重新解压
   一份放回去，或者换回「环境版」用系统里装的 Node。

Q：视频下下来没有声音？
A：正常不该出现——本包内置了 ffmpeg。检查 ffmpeg\ffmpeg.exe 是否还在；不在
   就重新解压放回去，再下一次。

Q：怎么更新？
A：浏览器脚本会通过 Tampermonkey 自动更新；服务端（save_images_server.js）
   不会自己更新，拿新版覆盖过去，然后重启服务。

Q：整个包很大？
A：大头就是 node\node.exe（约 90 MB）和 ffmpeg\ffmpeg.exe（约 100 MB）。带在
   包里是为了让别人什么都不用装；自己电脑已经有 Node 的话，下「环境版」就够。
