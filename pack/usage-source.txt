====================================================
  Bilibili-Plus v@@VERSION@@ · 源码版
====================================================

这是给要改代码的人准备的一份：用户脚本源码、便携版内核、构建脚本、打包发布
工具链、单测，都在里面。

只想用工具本身的话，请下这几个包（都在项目主页的发行包列表里喵）：
    portable  便携版，纯浏览器、零安装
    env       环境版，功能最全，需要自己装 Node
    full      完整版，内置 Node.js 与 FFmpeg，双击即用

----------------------------------------------------
一、需要什么
----------------------------------------------------
    Node.js 18+      https://nodejs.org/zh-cn/download
    （打完整版发行包时，本机还要有 node\ 和 ffmpeg\ 两个二进制目录）

好消息：这个项目是**零第三方依赖**，不用跑 npm install，克隆/解压完就能跑。

----------------------------------------------------
二、几条命令
----------------------------------------------------
    npm run build     # 生成「环境版」（根目录）和「便携版」两份用户脚本
    npm test          # 单测：便携版内核 + 打包工具链（有 Python 会交叉验证 ZIP）
    npm run check     # 语法自检
    npm start         # 跑本地保存服务（环境版）
    npm run pack      # 打四个发行包 → 发行版/
    npm run release   # 打包并发布到 GitHub Release（需要 GH_TOKEN 或 git 凭据）

只打某一个包、或输出到别处：
    node pack/pack.js --only env
    node pack/pack.js --no-build --out D:\某个目录

----------------------------------------------------
三、改哪儿
----------------------------------------------------
    src/bilibili-save.user.js     用户脚本源码（功能都在这）
    src/lib/browser-save.js       便携版内核（ZIP 打包/分批、已下载记账），
                                  会被内联进产物，别放 Node 专用代码
    build.js                      构建：源码 → 两份用户脚本
    pack/zip.js                   打包用 ZIP 写入器（中文名 EFS + CRC 校验）
    pack/notes.js                 发行包里每个文件的备注表（新文件记得补一条）
    pack/pack.js                  打四个发行包
    pack/publish.js               发 GitHub Release
    pack/usage-*.txt              各发行版的使用说明（打进包里的那份）
    tests/                        单测

注意：bilibili-save.user.js、便携版/bilibili-save.user.js 都是构建产物，别手改，
改完源码跑 npm run build 重新生成。

----------------------------------------------------
四、文件都是干啥的
----------------------------------------------------
见同目录的「文件说明.txt」：包内每个文件一条备注。
