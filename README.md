# Bilibili-Plus

B 站图片和视频的批量下载工具，一个油猴脚本 + 一个跑在本机的 Node 服务。

脚本负责在页面上找东西：把缩略图地址还原成原图、把视频的真实地址从接口里翻出来。找到之后它自己存不了，因为**浏览器没法直接往硬盘写文件**，落盘这件事只能交给本地那个服务。

听着绕，但这是纯网页绕不过去的坎。平时用不着你操心，双击一下它们自己就串起来了。

## 装

需要 Node.js 18 以上，就这一个要求（没有额外依赖，纯内置模块，不用 npm install——我个人挺烦装个东西先拉几百兆 node_modules 的）。

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)。没听过的话，它就是个跑这种 `.user.js` 脚本的扩展
2. 把 `bilibili-save.user.js` 拖进浏览器，会弹安装页，点确认
3. 双击 `一键启动.bat`。它会蹦出个黑窗口跑服务，顺手帮你把 B 站打开

黑窗口别关，关了服务就没了，页面上会提示「未连接本地保存服务」。

电脑上没 Node 的话，用 `无需环境直接安装版` 那个文件夹，里面塞了 Node 和 ffmpeg，双击里面的 `一键启动.bat` 就能跑，一行都不用配（它跟上面那个不一样，下下来的东西存它自己文件夹里，不往桌面塞）。

## 用

**图片**：打开收藏夹、动态、作品页，它会自己开始存，不用你点。要是你只是进来看看图、不想它一股脑全下下来，就在地址后面加个 `?bili_auto_save=0` 把自动的关掉；想手动存就点右下角的「提取并保存」。

**视频**：点右下角「视频下载」。面板会把当前这个视频、它的分 P（就是那种 `p=2`、`p=3` 的），还有页面右边那个订阅合集都列出来，你要哪个勾哪个，勾完点下载。合集几百个也能一把梭。

**审查模式**：设置里切过去之后，图片就不直接存了，先一张张给你看。↓ 存当前这张，← → 翻页，Esc 退出，看不上的直接跳过，省得一堆图下回来再手动删。键位嫌不顺手就在左边改，改完记着的，下次打开还是这套。

## 文件存哪

默认丢到桌面的 `B站下载` 文件夹，没这个文件夹服务会自己建：

```
B站下载/
├── xxx.png          # 图片，文件名是原图 hash
└── videos/          # 视频
```

图片和视频分开放，图片铺在根目录，视频都塞在 `videos/` 里。用 `无需环境直接安装版` 的话，这个"根目录"就是它里面的 `bilibili_images\`，结构一模一样。图片名是原图的 hash，看着像乱码，但保证不重名——早期版本拿标题当文件名，一百多张图缩成几十个名字互相覆盖，白丢一半，血泪教训。

想换地方在设置面板里填就行，填哪存哪，清空就恢复成默认的。视频实际存哪，下载面板底下会写出来，不用自己满硬盘找。

macOS / Linux 没有 bat，直接跑服务就行，目录可以从命令行或者环境变量传：

```bash
node save_images_server.js ~/Pictures/bili                # 命令行
BILI_SAVE_DIR=~/Pictures/bili node save_images_server.js  # 或者环境变量
```

Windows 上不用折腾命令行，`一键启动.bat` 里留了一行 `set "SAVE_DIR="`，填上就行。

## 一些细节

- 图片会自动把 `@316w_560h` 这种缩略图后缀去掉，直接去要原图；webp / avif 的把地址后缀换成 `.jpg` 再要一次，能拿到 jpg 版
- 视频走 B 站的 playurl 接口拿 DASH 流，画质尽量挑高的。装了 ffmpeg 就合并成一个带声音的 mp4，没装就音视频分开存（`.video.mp4` + `.audio.m4a`，能看，就是得自己拼）
- ffmpeg 放项目目录的 `ffmpeg\ffmpeg.exe` 也行，系统 PATH 里有也行，两处都找不到才会分开存
- 下过的视频会标上「✅ 已下载」，「全选未下载」和下载的时候都会跳过，不至于白白浪费流量——一口气下几百个的时候这个挺省事
- 服务端那边也做了查重，同一个文件不会重复下
- 收藏夹、动态、作品（opus）都能批量，订阅合集一次把列表全拉下来（上限 500 个），不用一个个点进去翻
- 服务跑的端口是 8765，就本机自己用，不对外

## 常见问题

**提示「未连接本地保存服务」**

服务没启动，或者黑窗口被你手滑关了。再双击一次 `一键启动.bat`，然后刷新 B 站页面。

**有些图片下不了**

一般是得登录才能看的图（私密收藏夹、部分作者的图）。本地服务是裸请求，没有你的登录态，B 站那边的权限它绕不过去，这种只能自己手动存。

**视频列表是空的，或者拿不到下载地址**

先看看服务是不是在跑——多半是黑窗口关了。要是只有个别视频不行，可能是那视频有会员或者地区限制，这种就真没辙。

**视频下下来没声音**

没装 ffmpeg。装上重新下一遍就行，或者直接用配套那个 `.audio.m4a`，自己拿播放器对一下也能看。

**图片名怎么像乱码**

那是原图的 hash，不是乱码。用 hash 就是为了绝对不重名，省得标题一样的图互相覆盖。

**怎么更新**

Tampermonkey 会按脚本里的 `@updateURL` 自动检查更新，也可以删掉旧的重新导入一次。服务端（`save_images_server.js`）不会自己更新，要更新就把新文件覆盖过去，再把服务重启一下。
