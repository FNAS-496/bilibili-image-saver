# Bilibili-Plus 🐾

B 站图片和视频的批量下载工具喵~ (=^･ω･^=)

喵呜~ 欢迎欢迎！本喵是这里的看板猫，今天来给你介绍一下这个小工具喵🐾

这东西有两个版本，随便挑一个顺手的就好啦~

- **便携版**：纯浏览器的小懒猫，什么都不用装喵！图片打包成 ZIP、或者悄悄塞进你挑的文件夹；视频嘛，可以一个一个乖乖下载，也可以打包成 ZIP 一整个叼走~
- **环境版**：油猴脚本 + 一个蹲在本机的小服务喵。会偷偷帮你把文件写进硬盘、能 4K、能合音画，还自带图片相册页哦~

两个版本的用户脚本是**同源**的喵（`src/` 里就一套源码，build 一下变出两份产物），所以功能大差不差，差的只是那些确实非本地环境不可的活儿啦喵。

## 两个版本，挑一个顺手的喵🐾

| | **便携版**（`便携版/`） | **环境版**（仓库根目录） |
|---|---|---|
| 要先装什么 | **什么都不用装哦** | Node.js 18+（想合并音画再装 ffmpeg 喵） |
| 图片怎么存 | 打包成 ZIP 下载（大了会自动分卷喵），或写进你选的文件夹 | 后台直接写进任意绝对路径，静悄悄、不用点 |
| 视频怎么存 | B 站官方 mp4 单文件（≤1080P，**自带音轨**，不需要 ffmpeg 喵）；可选逐个下载或打包成 ZIP（自动分卷） | DASH 音视频流 → 用 ffmpeg 合并成 mp4（可 4K/HDR 喵） |
| 已下载标记 | 浏览器本地记账 | 服务端扫目录 + 扫库 |
| 图片相册页 | ❌（要本地服务喵） | ✅ `http://127.0.0.1:8765/` |

便携版里**该有的按钮都在喵**，只有少数确实要本地环境的功能，会先轻轻提醒你一次：

> 🔌 这个功能需要本地环境喵 → 会乖乖把 Node.js / ffmpeg / 环境版 的下载地址递给你

这个提醒**只会冒出来一次**（本喵记在小本本上了，绝对不是每次刷新都来烦你的坏猫喵），而且你还可以：
- 在「设置 → 功能与提示」里把它重新打开、或者干脆关掉；
- 勾上「**去除无关功能**」，把所有需要环境的功能藏起来，界面就只剩开箱即用的那部分啦，清清爽爽喵~

## 本喵会些什么（功能介绍）🐾

**开箱即用（两个版本都有喵）**

- 🖼️ **原图批量保存**：收藏夹 / 动态列表 / 动态详情 / 作品（opus）/ 空间页，本喵会把缩略图变回原图再存好哦；webp / avif 会换个地址再要一次 jpg 版喵
- 🔍 **审查模式**：图片先一张张给你过目喵，↓ 存当前、← → 翻页、Esc 退出，键位随你改，改完还记得，本喵的记性可好了
- 🎬 **视频批量下载**：当前视频、分 P、右侧订阅合集都能勾着批量下喵（不限数量哦，大合集本喵分页给你拉全）；已下载的自动跳过，不浪费流量
- 🗂️ **已下载标记**：列表上标「✅ 已下载」，「全选未下载」和下载的时候都会跳过喵
- 🔥 **页面增强**：只看大图、点赞 / 关注 / 收藏状态检测、日夜主题，看久了也不累眼睛喵
- 📖 **功能介绍面板**：第一次用会自动弹一次喵，之后在「设置」里随时能打开

**需要本地环境（Node.js + ffmpeg，也就是环境版喵）**

- 🎞️ **4K / HDR / 音画合并**：DASH 音视频流用 ffmpeg 合并成带声音的 mp4（便携版只能走官方单文件 mp4，最高 1080P 喵）
- 🖼️ **图片相册页**：本机 `127.0.0.1:8765` 页面里慢慢翻已存的图，像翻相册一样喵
- ⚡ **静默自动落盘**：后台写进你自定义的绝对路径，全自动、不用点喵，你只管看图就好

## 装喵🐾

### 便携版（本喵推荐先试这个，零安装喵）

1. 浏览器先装 [Tampermonkey](https://www.tampermonkey.net/)。没听过？它就是个专门跑这种 `.user.js` 脚本的小扩展啦
2. 把 `便携版/bilibili-save.user.js` 拖进浏览器，弹出安装页，点确认喵
3. 完事~ 打开 B 站就能用啦，本喵已经在里面等你了喵

图片会打包成 `B站图片_日期_时间.zip` 掉进浏览器「下载」文件夹，解压就好喵。图特别多、特别大的时候，本喵会自动分成 `_part1`、`_part2`… 好几个 ZIP，绝对不会硬塞给你一个胖乎乎的包喵。想直接写进文件夹（Chrome / Edge 才行哦），去设置里切「写入授权目录」，再点一下「选择文件夹」就好喵。

视频默认一个一个下载；想让本喵打包的话，把「设置 → 视频下载方式」切成「打包成 ZIP」就行（太大了也会自动分卷喵）。

### 环境版（想要 4K / 静默落盘 / 相册页就选它喵）

需要 Node.js 18 以上，就这一个要求哦（没有额外依赖，纯内置模块，不用 npm install——本喵也挺烦装个东西先拉几百兆 node_modules 的，太占猫窝了）。

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)
2. 把根目录的 `bilibili-save.user.js` 拖进浏览器，点确认喵
3. 双击 `一键启动.bat`。它会蹦出个小黑窗口跑服务，顺手帮你把 B 站也打开，可贴心了喵

黑窗口别关呀，关了服务就没啦，页面上会提醒你「未连接本地保存服务」，像小猫挠门一样急喵。

电脑上没 Node 的话，用 `无需环境直接安装版` 那个文件夹喵，里面塞好了 Node 和 ffmpeg，双击里面的 `一键启动.bat` 就能跑，一行都不用配（它跟上面那个不一样哦，东西都存在它自己的小窝里，不往桌面塞喵）。

## 怎么用喵🐾

**图片**：打开收藏夹、动态、作品页，本喵会自己开始存，不用你动手。要是你只是进来随便逛逛、不想它一股脑全下下来，就在地址后面加个 `?bili_auto_save=0`，把自动的关掉；想手动存就点右下角的「提取并保存」喵。

**视频**：点右下角「视频下载」。面板会把当前这个视频、它的分 P（就是那种 `p=2`、`p=3` 的）、还有页面右边那个订阅合集都列出来，你要哪个勾哪个，勾完点下载喵~ 合集再大也能一把梭，列表不限数量哦（本喵分页自动拉全，拉得满满当当）。

**审查模式**：设置里切过去之后，图片就不直接存啦，先一张张给你看。↓ 存当前这张，← → 翻页，Esc 退出，看不上的直接跳过，省得一堆图下回来再手动删喵。键位嫌不顺手就在左边改，本喵记着呢，下次打开还是这套，尾巴都记住啦。

## 文件存哪喵🐾

**环境版**：默认丢到桌面的 `B站下载` 文件夹喵，没这个文件夹的话服务会自己建：

```
B站下载/
├── xxx.png          # 图片，文件名是原图 hash
└── videos/          # 视频
```

图片和视频分开住喵，图片铺在根目录，视频都塞在 `videos/` 里。用 `无需环境直接安装版` 的话，这个"根目录"就是它里面的 `bilibili_images\`，结构一模一样。图片名是原图的 hash，看着像乱码，但保证不重名喵——早期版本拿标题当文件名，一百多张图缩成几十个名字互相覆盖，白丢一半，血泪教训喵呜呜。

想换地方的话，在设置面板里填就行喵，填哪存哪，清空就恢复成默认的。视频实际存哪，下载面板底下会写出来，不用自己满硬盘找啦。

macOS / Linux 没有 bat，直接跑服务就行，目录可以从命令行或者环境变量传喵：

```bash
node save_images_server.js ~/Pictures/bili                # 命令行
BILI_SAVE_DIR=~/Pictures/bili node save_images_server.js  # 或者环境变量
```

Windows 上不用折腾命令行，`一键启动.bat` 里留了一行 `set "SAVE_DIR="`，填上就行喵。

**便携版**：图片默认打包成 ZIP，落在浏览器「下载」文件夹（Chrome / Edge 可以设成每次询问保存位置喵），想直接写进文件夹就切「写入授权目录」；Firefox / Safari 没有这个接口哦，只能走 ZIP。视频看你选的下载方式：逐个下载 / 打包 ZIP / 写进授权目录，都可以喵。

## 一些细节喵🐾

- 图片会自动把 `@316w_560h` 这种缩略图后缀去掉，直接去要原图喵；webp / avif 的把地址后缀换成 `.jpg` 再要一次，能拿到 jpg 版
- 视频走 B 站的 playurl 接口拿 DASH 流，画质尽量挑高的。装了 ffmpeg 就合并成一个带声音的 mp4，没装就音视频分开存（`.video.mp4` + `.audio.m4a`，能看，就是得自己拼喵）
- ffmpeg 放项目目录的 `ffmpeg\ffmpeg.exe` 也行，系统 PATH 里有也行，两处都找不到才会分开存喵
- 下过的视频会标上「✅ 已下载」，「全选未下载」和下载的时候都会跳过，不至于白白浪费流量——一口气下几百个的时候这个挺省事喵
- 服务端那边也做了查重哦，同一个文件不会重复下
- 收藏夹、动态、作品（opus）都能批量，订阅合集一次把列表全拉下来（不限数量），不用一个个点进去翻喵
- 服务跑的端口是 8765，就本机自己用，不对外喵，安全得很

## 常见问题喵🐾

**提示「未连接本地保存服务」**

服务没启动，或者黑窗口被你手滑关了喵。再双击一次 `一键启动.bat`，然后刷新 B 站页面就好啦。（便携版压根不连本地服务哦，这条提示只属于环境版喵。）

**有些图片下不了**

一般是得登录才能看的图喵（私密收藏夹、部分作者的图）。本地服务是裸请求，没有你的登录态，B 站那边的权限它绕不过去，这种只能自己手动存啦，本喵也帮不上忙喵呜呜。

**视频列表是空的，或者拿不到下载地址**

先看看服务是不是在跑喵——多半是黑窗口关了。要是只有个别视频不行，可能是那视频有会员或者地区限制，这种本喵也真没辙了呜呜。

**视频下下来没声音**

环境版：没装 ffmpeg 喵。装上重新下一遍就行，或者直接用配套那个 `.audio.m4a`，自己拿播放器对一下也能看。
便携版：本喵优先下官方「音视频合一」的 mp4，正常都带声音；少数只有分开的流，会存成 `.video.mp4` + `.audio.m4a` 并提示你一次，合并需要 ffmpeg，用环境版就好喵。

**图片名怎么像乱码**

那是原图的 hash，不是乱码呀~ 用 hash 就是为了绝对不重名，省得标题一样的图互相覆盖喵。

**便携版存的图跑哪去了**

打包成了一个 ZIP，在浏览器「下载」文件夹里喵（Chrome / Edge 可以设成每次询问保存位置）。想直接写进文件夹就切「写入授权目录」；注意 Firefox / Safari 没有这个接口，只能用 ZIP 哦。

**便携版的「✅ 已下载」怎么和我实际文件对不上**

便携版没法去扫你的硬盘喵，用的是浏览器本地记账（IndexedDB）。你把文件删了它不知道呀，这时候在「设置 → 功能与提示 → 清空已下载记录」重置一下就好喵。

**图 / 视频太多，会打包成一个超大 ZIP 吗**

不会的喵~ 单包超过 4GB 或者文件数太多时，本喵会自动分卷成 `_part1`、`_part2`… 依次下载；视频打包还额外按约 2GB 控制单包（照顾内存喵）。放心勾，数量没有上限哦。

**怎么更新**

Tampermonkey 会按脚本里的 `@updateURL` 自动检查更新喵，也可以删掉旧的重新导入一次。便携版**不做**自动更新（免得被替换成需要环境的环境版喵），要更新就重新下载覆盖安装。服务端（`save_images_server.js`）不会自己更新哦，要更新就把新文件覆盖过去，再把服务重启一下喵。

## 开发 / 构建喵🐾

两个版本的用户脚本**同源**喵：改 `src/bilibili-save.user.js`（浏览器保存内核在 `src/lib/browser-save.js`），然后跑构建生成两个产物：

```bash
npm run build     # 生成 环境版(根目录) + 便携版脚本（顺带同步"无需环境直接安装版"）
npm test          # 便携版内核单测（ZIP 字节与 Python 独立实现比对 + 构建产物检查）
npm run check     # 语法自检（src 与便携版产物）
npm start         # 跑本地保存服务（环境版）
```

> `bilibili-save.user.js` 和 `便携版/bilibili-save.user.js` 都是**生成出来的**喵，别直接改；改了 src 再跑一次 build 就好。
