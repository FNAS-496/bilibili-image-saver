====================================================
  Bilibili-Plus 便携版 · 无需安装任何环境
====================================================

本版本只有一个文件：bilibili-save.user.js（浏览器用户脚本）。
不需要 Node.js，不需要 ffmpeg，不占端口，不常驻后台。
（需要 4K / 音画合并 / 相册页时请看文末「需要本地环境的功能」。）


----------------------------------------------------
一、功能介绍
----------------------------------------------------

【开箱即用 · 无需任何环境】

  🖼️ 原图批量保存
      收藏夹 / 动态列表 / 动态详情 / 作品(opus) / 空间页都能自动提取原图并保存。
      缩略图地址会自动还原成原图；webp / avif 会换地址再要一次 jpg 版。

  🔍 审查模式
      图片先一张张给你看：↓ 存当前、← → 翻页、Esc 退出。
      键位可以自己改，改完记着，下次打开还是这套。

  🎬 视频批量下载
      当前视频、分 P（p=2、p=3 那些）、右侧订阅合集都能勾选批量下（不限数量）。
      便携版下的是 B 站官方「音视频合一」的 mp4：一个文件、自带音轨、最高 1080P，
      全程不需要 ffmpeg。想打包成一个 ZIP：设置 → 视频下载方式 → 「打包成 ZIP」，
      太大或太多会自动分成 part1、part2… 几个包。

  🗂️ 已下载标记
      下载过的会标「✅ 已下载」，「全选未下载」和下载时都会跳过，省流量。

  🔥 页面增强
      只看大图、点赞 / 关注 / 收藏状态检测、日夜主题。

  📖 功能介绍面板
      第一次用会自动弹出来一次，之后在「设置 → 功能与提示」里随时能打开。


----------------------------------------------------
二、怎么装（一次就好）
----------------------------------------------------

  1. 浏览器装 Tampermonkey 扩展
     https://www.tampermonkey.net/
     （Chrome / Edge 应用商店里搜 Tampermonkey 也行）

  2. 把 bilibili-save.user.js 拖进浏览器窗口
     会弹出安装页，点「安装」即可。

  3. 完事。打开 B 站就能用。


----------------------------------------------------
三、怎么用 / 文件存哪
----------------------------------------------------

  图片：打开收藏夹、动态、作品页，点右下角「⬇️ 提取并保存」。
        默认会把这一批图片打包成一个 ZIP 下载：
              B站图片_20261002_183000.zip
        落在浏览器「下载」文件夹里，解压即可。
        图特别多 / 特别大时会自动分成 _part1、_part2… 多个 ZIP，不用一次下太多。

  想直接写进文件夹（Chrome / Edge）：
        设置 → 保存位置 → 选「写入授权目录」→ 点「选择文件夹」。
        授权一次后会记住，之后直接写进去，不产生 ZIP。
        （Firefox / Safari 没有这个接口，只能用 ZIP 方式。）

  视频：点右下角「📹 视频下载」，勾选后点「下载选中」。
        单文件 mp4 会直接下载（或写进你授权的目录）；选了「打包成 ZIP」
        就打包成一个包下载，太大自动分卷（写进授权目录时同样支持）。

  保存位置：默认就是浏览器的「下载」文件夹。
        Chrome / Edge 可以在浏览器设置里打开「下载前询问每个文件的保存位置」。


----------------------------------------------------
四、需要本地环境的功能（Node.js + ffmpeg）
----------------------------------------------------

便携版里这些按钮依然保留，用到时会提示你一次，并给出下载地址：

  🎞️ 4K / HDR 与音画合并   —— 需要 ffmpeg
       只有少数视频只提供音画分离的 DASH 流，合并成带声音的 mp4 需要 ffmpeg。

  🖼️ 图片相册页            —— 需要本地服务
       127.0.0.1 上的网页相册，用来浏览已经存下来的图片。

  ⚡ 静默自动落盘          —— 需要本地服务
       后台直接写进你指定的任意绝对路径，全自动、不用点确认。

  下载地址：
       Node.js ：https://nodejs.org/zh-cn/download
       ffmpeg  ：https://www.gyan.dev/ffmpeg/builds/
       环境版  ：https://github.com/FNAS-496/bilibili-image-saver
                （用根目录的「一键启动.bat」启动本地服务即可；
                  也可以用「无需环境直接安装版」，里面已经内置了 Node 和 ffmpeg）

  提示策略（都在「设置 → 功能与提示」里）：
       ☑ 需要环境的功能「仅提示一次」
            默认开启。提示过一次就不再烦你，不是每次刷新都弹。
            （想再看一次：把这个勾去掉再勾回来）
       ☐ 去除无关功能：隐藏需要本地环境的功能
            勾上就把上面这些按钮全隐藏，界面只剩开箱即用的部分。


----------------------------------------------------
五、常见问题
----------------------------------------------------

  Q：提示「未连接本地保存服务」？
  A：那是环境版才会有的提示。便携版不会连本地服务；如果你用的是环境版，
     双击「一键启动.bat」启动服务后刷新页面即可。

  Q：图片下载下来是个 ZIP，能直接存成一张张吗？
  A：可以。设置里切到「写入授权目录」并选择文件夹（Chrome / Edge）。

  Q：打包几百张图会不会很慢 / 很占内存？
  A：ZIP 用的是 STORE 方式（图片本来就压缩过，不再二次压缩），几乎不耗 CPU；
     打包过程在内存里拼装后一次性交给浏览器下载。单批合计超过约 4GB（或文件数
     超过 65535）会自动分成多个 ZIP（_part1、_part2…）依次下载，不用管。

  Q：便携版的「✅ 已下载」和我硬盘上的文件对不上？
  A：便携版没法扫你的硬盘，用的是浏览器本地记账。你把文件删了它不知道，
     这时在「设置 → 功能与提示 → 🧹 清空已下载记录」重置一下就好。

  Q：视频只有画面没声音？
  A：便携版优先下官方音视频合一的 mp4，正常是带声音的。极少数视频只提供
     分开的流，会存成 .video.mp4 + .audio.m4a 并提示一次；合并需要 ffmpeg。
     （注意「打包成 ZIP」模式要先把整段视频读进内存，超大视频建议还是逐个下载。）

  Q：便携版会自动更新吗？
  A：不会（避免被自动替换成需要环境的环境版）。要更新重新下载覆盖安装即可。
