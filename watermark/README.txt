放置你的微信收款码（打赏二维码）到本目录：

  1. 微信 → 我 → 收付款 → 二维码收款 → 保存收款码图片
  2. 把图片放入本目录（任意命名，支持 png / jpg / jpeg / webp / gif）
     推荐命名：wechat_qr.png 或 wechat_qr.jpg
     （当前目录已有一张 wechat_qr.jpg，可随时替换成你自己的）

效果：每次下载成功后，页面右下角会弹出「下载成功」面板，
面板中显示：
  - 收款码（来自本目录的收款码图片）
  - 作者名「似玖得六（FNAS）」、GitHub 链接、邮箱
  - 「觉得好用的话就打赏一杯奶茶钱吧 ☕」

注意：
  - 没有放图片时，面板仍会显示作者/GitHub/邮箱文字，只是不显示收款码。
  - 放好/替换图片后需重启本地服务（一键保存.bat）。
  - 本目录已被 .gitignore 忽略，不会提交到 GitHub，保护你的收款隐私。
